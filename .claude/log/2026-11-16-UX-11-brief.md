# UX-11 brief (Design mode, no code) — studio-ux-dev

Read `.claude/standards/dev-standards.md` first. Sections that matter: "Quality bar" (UI: themes via CSS variables, Emerald default, matte, short labels, phone 390/360 px checks), "Production and assistant rules", and "How we work".

## The owner's words (HQ request, 15 Nov 2026)
"When Keys generates an element like drums, you can't mute the individual elements from it, like open hats etc. Enable that."

## The job
Design per-sound mute (and probably solo) inside a drum part: kick, clap, snare, closed hat, open hat, percussion... A Keys drum part is one track whose events are MIDI notes on a kit (`isDrumTrack`, `drumRows`, `DRUM_ROWS`, `DRUM_LABEL`, `drumPiece` in `src/daw.js`; the step sequencer editor). Today only the whole track mutes (`t.mute`/`t.solo` in `src/daw.js`).

Cover in the proposal:
1. Where the per-sound M / S lives: in the drum step editor's row labels for sure; consider a quick way from the track list too (e.g. a small "sounds" pop-over on a drum track) without cluttering it. Show both in mockups (desktop 1400x900 and phone 390x844), using the real studio build as the base (build it, open a Keys drum part, capture, then mock the change).
2. What muting does to playback (live play, loop, Song mode, MP3 export) and how it is stored (per track, e.g. `t.muteNotes` set of drum pitches; saved, undoable through `saveProject`). Where the scheduler change goes (which file and owner; if it's a sound-engine file say so and keep that part tiny).
3. Voice: "Keys, mute the open hats", "solo the kick", "bring the claps back", "unmute everything" — a new assistant action needs the Worker prompt + `actions.js` + `maker.js` (assistant-dev builds that part; spell out the action name and fields so assistant-dev can build it as written).
4. Edge cases: "another one" (a new groove) keeps or clears the mutes? A sound that is muted but has no notes in the new groove? Duplicate track, Song-mode patterns A/B, a part made by the user (Beat button) as well as by Keys.
5. Effort, risks, at most 3 decisions for the owner with your recommendation.
