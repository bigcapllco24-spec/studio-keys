## The bugs
1. **MEDIUM — "afro house beat" makes plain house** (909 kit, clap, 124 BPM); "make an afro house groove with congas" too. Cause: `STYLE_WORDS` checks house before afro. Expected: the afro style (as the live Worker prompt sends `afro`). Check other compound genres for the same ordering problem (e.g. "afro tech", "deep tech", "lofi house", "melodic techno" vs "techno", "uk garage" vs "garage", "minimal techno") and list what you fixed.
2. **MEDIUM — "unsolo the bass" writes a new bassline and leaves it soloed; "un-mute the drums" mutes them; "remove the solo" isn't understood.** Cause: the `mixVerb` rule. Expected: unsolo / unmute / "remove the solo" / "clear all solos" / "unmute everything" do exactly that.
3. **MEDIUM — "quantize my melody to 1/8" adds a new Melody track; "quantize it", "tighten up the timing" aren't understood.** The `quantize` action exists in actions.js and the Worker prompt; maker.js has no rule. Expected: offline quantize with the grid if said (1/4, 1/8, 1/16, "16ths", triplets if the action supports them), the named track or the selected one.
4. **LOW — two requests in one sentence go wrong.** "more reverb on the chords and less on the melody" turns the chords' reverb DOWN; "make the drums louder and the bass quieter", "mute the drums and solo the bass", "set the tempo to 128 and add a shaker" each do only one half and the reply doesn't say what was skipped. Expected: split on "and"/","/"then" when both halves parse as commands, and do both (in order, one undo step if the code makes that easy); if a half can't be done offline, say which part was skipped. Never apply one half's direction (more/less) to the other's target.
5. **LOW — Keys names an artist you didn't say.** "drums like Black Coffee" → "Keinemusik-style drums"; "lofi hip hop beat" → "Lofi Girl-style drums", and that name is saved as the song's reference (`PROJ.ref`). Expected: the reply and the reference use the name the user said ("Black Coffee-style"; plain "lo-fi" when no artist was named). Check the live path (actions.js) too, not just maker.js, and note if `ARTISTS` needs an alias tweak (you own `ARTISTS`).

Also, only if it's small and in your files: typo tolerance for the commonest words ("basline", "anothr one", "melodie") — skip if it gets risky, and say so.
