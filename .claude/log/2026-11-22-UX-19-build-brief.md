Bug (found by the tester in the AI-9 re-check 2, `.claude/work/reports/AI-9-retest2.md` line ~100): `setKey` in `src/studio.js` only transposes notes when a key was set before. On a loop whose key is still "Key: auto", choosing a key (the Key menu, or Keys' `{type:'key', key:'F# minor'}` action) changes the label but leaves the notes where they were, so the song now claims "F sharp minor" while it plays something else ("is the bass in F sharp or G flat?" then answers "plays A, F and G, in F sharp minor").

Fix:
1. When the user picks a key (Key menu in `studio.js`, and the assistant's `key` action `ACT.key` in `src/actions.js` line ~160: you may make that one-line change in actions.js, list it in your report) and the current key is auto, find the loop's key from its pitched notes (`detectKey`, as `edit.js`/`assistant.js` already do; use all pitched, non-percussive tracks and their patterns) and transpose by the shortest distance from that to the new tonic, exactly like the existing known-key path. If no key can be found (no pitched notes, or fewer than about 4), only set the label, as now.
2. Internal callers that fill in a detected or artist key when the key is auto (`actions.js` lines ~88 and ~123, `assistant.js` ~179, `edit.js` ~76, `studio.js` ~249) must NOT move notes: they set the key the notes are already in, or a key for parts not made yet. Keep them as they are (e.g. an explicit option like `setKey(k,{move:true})` used only by the two user paths above). In particular a vibe/artist key set over the user's sung parts must never transpose what they sang (owner rule: sung parts keep the user's notes as sung).
3. Drums and percussive instruments never move (as now). Songs with patterns/sections (AI-1 Song mode) move every pattern, as the known-key path does. One undo step.
4. Smoke lines in `tests/smoke.mjs` (append at the end; other branches also append there): auto key + C-minor loop → Key menu "D minor" → notes +2 and label D minor; the same through the offline assistant ("set the key to F sharp minor"); undo restores both notes and "auto"; an artist/vibe key over a sung bass does not move it.
