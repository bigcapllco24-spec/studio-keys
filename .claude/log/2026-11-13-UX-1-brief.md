Standards that matter most here (quoted):

- "UI: three colour themes ... Velvet (default) ... Sapphire ... Emerald. Matte: solid colours, no gradients or glows. All colours come from CSS variables ... canvases read them through `TC`. ## The item
A longer timeline where you place sections and clips across a whole song, like Ableton's arrangement view, instead of one repeating loop. Done when: a 3-minute song can be laid out, edited and played through. Size L.

## Research
Read `.claude/research/RES-2-song-structure.md`, especially "For the devs → For studio-ux-dev (UX-1)". Key notes: section strip on top (resize, move with content, Alt-drag / Cmd+D duplicate, double-click to loop); track lanes where clicking a cell toggles a part and `0` mutes; bar ruler with loop brace, following playhead, zoom (+/-, Cmd+scroll, W to fit, pinch); Loop/Song switch like FL's PAT/SONG; tablet 44 pt handles and long-press menu, phone shows a song map only; draw only visible bars; render MP3 export in chunks (a 6-minute render is ~127 MB of float audio); flash the cells the assistant changed and show an Undo chip. The sound engine may later take each section's role (fill at the end of a Build, crash on a Drop); note what hooks you'd leave for that, but sound changes are not in this item.

## Shared song layout (both AI-1 and UX-1 design against this; flag it clearly if you need to change it)
UX-1 (studio-ux-dev) owns the data model and the screen; AI-1 (assistant-dev) owns the voice actions that edit it. They are designed in parallel this check-in, so both start from this draft:
- `project.sections = [{id, name, bars, parts: {<trackId>: {on: true|false, variant: <patternId>}}}]`, ordered; the song plays sections in order. A section's length is in bars (multiples of 4 recommended, 4-64).
- Each track's current loop becomes its first pattern; patterns are linked (editing a pattern changes every section that uses it), with "Make unique" to fork one for a section.
- A song with no `sections` opens as one section the length of today's loop, so old songs keep working.
- Loop/Song switch: Loop plays the current loop as today; Song plays the sections in order.
- Default template (melodic house/techno, 124 bpm): Intro, Build, Drop, Break, Drop 2, Outro at 16 bars each (96 bars, about 3:06); "club" length uses 32 bars each.
- Every change (by click or by voice) goes through `saveProject`, one undo step per request.
