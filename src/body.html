    Extracted element

    4 · Make it playable

    Sampler plays the real slice, pitched across your keys. Synth rebuilds the sound from its measured harmonics and envelope, so long notes sustain cleanly.
    How extraction works (for the dev team)
    1. The selected region (max 20 s) goes through a short-time Fourier transform (2048-point Hann, hop 512) in a Web Worker.
    2. Three soft masks are multiplied per time–frequency bin: a stereo mask from left/right similarity, a harmonic/percussive mask from median filtering, and a band mask for the element's frequency range.
    3. The masked spectrum is resynthesized by overlap-add. Drum elements take the strongest onset; tonal elements run an NSDF pitch tracker that tolerates octave jumps and take the longest stable note.
    4. The slice is analyzed for root pitch, harmonic amplitudes, spectral centroid, flatness, envelope and stereo width, which build the resynth patch.
    5. To plug in an ML separator (Demucs, an ONNX model or your own API), register it in SEPARATION_ENGINES: it receives left/right PCM, sample rate and the element recipe and returns a mono Float32Array.
